# 그림 요청서 — 도트 그래픽 (2026-11-26)

게임 화면은 이미 「도트 모드」(작은 캔버스 → 32색 → 각지게 확대)로 바뀌었다. 이제 코드로 그린 도형 대신 **AI로 만든 그림을 도트로 바꿔** 넣는다.
분위기 참고: 어두운 16비트 쿼터뷰 공포·생존 게임(보라·남색 그림자, 창문 빛줄기). **특정 게임의 그림을 따라 그리지 않는다** — 프롬프트에 다른 게임 이름을 넣지 않는다.

## 만드는 방법
1. ChatGPT(또는 다른 이미지 AI)에 아래 프롬프트를 **한 장에 하나씩** 넣는다.
2. 받은 그림을 `art/raw/<파일명>.png`로 저장소에 올리거나 채팅에 올린다.
3. Claude가 `tools/pixelize.py`로 게임 팔레트 32색 도트로 바꿔 `art/<파일명>.png`에 두고 게임에 연결한다.

## 모든 그림 공통 규칙
- 배경은 **단색 마젠타 `#FF00FF`** (도구가 귀퉁이 색을 투명으로 지운다). 바닥 타일만 예외(배경 없이 꽉 채움).
- **글자·숫자·로고 금지**(간판 글씨는 게임 코드가 한글로 쓴다).
- 시점: 위에서 비스듬히 내려다보는 **3/4 탑다운**(16비트 RPG 시점). 정면 = 아래를 보는 모습.
- 바닥 그림자를 넣지 않는다(게임이 그린다). 몸 전체가 잘리지 않게.
- 색: 어둡고 채도 낮게, 그림자는 차가운 보라·남색. 피·네온만 선명하게.
- 시트는 **칸 수를 정확히**, 칸 간격을 똑같이.

### 공통 꼬리말 (모든 프롬프트 끝에 붙인다)
```
16-bit pixel art, top-down 3/4 RPG view, modern Seoul zombie apocalypse, dark muted palette with cool purple-blue shadows, crisp pixels, solid flat magenta (#FF00FF) background, no ground shadow, no text, no letters, no logos
```

