# 서울, 잔류자 — 기획안 (2026-11-25)

쿼터뷰 시점에서 탐색·제작·거점을 함께 하는 생존 장르. 제드존류의 게임 방식만 참고하는 원작 기획이며 이름·인물·그림·맵은 모두 새로 만든다.

## 1. 한 줄 콘셉트
감염 40일째, 봉쇄된 서울. 아파트 옥상 거점 하나로 시작해 한강을 건너 남산 송신소까지 가서 구조 신호를 보낸다.
- 장르: 쿼터뷰 생존 RPG (탐색·제작·거점·전투)
- 플랫폼: 모바일 세로 기본, PC 브라우저 지원
- 한 판 길이: 출정 한 번에 5~10분, 전체는 게임 속 약 60일

## 2. 핵심 순환
거점(아파트 옥상) 준비 → 서울 구역 하나로 출정(낮/밤, 소음, 무게 관리) → 귀환(실패하면 가방 잃고 부상) → 제작·시설 강화·동료 치료 → 하루 지남(배고픔·감염·계절) → 무전 사건·세력 의뢰로 새 구역.

## 3. 서울 지도
| 구역 | 얻을 것 | 위험·특징 |
|---|---|---|
| 노원·상계 아파트 단지(시작) | 생활용품, 통조림 | 좁은 복도, 갇히기 쉬움 |
| 동대문·광장시장 | 천·식재료·공구 | 미로 골목, 소음 잘 퍼짐 |
| 종로·고궁 | 약초, 은신처 | 담장 덕에 안전, 약탈단 거점 |
| 명동·을지로 | 약국, 소독용 알코올 | 지하상가 연결, 어두움 |
| 지하철 2호선 | 빠른 이동 | 손전등 필수, 좀비 무리 |
| 용산 옛 기지터 | 무기·방호구 | 무장 잔존 세력 |
| 여의도 | 발전기·연료 | 방송국 무전 이벤트 |
| 노량진·가락 시장 | 대량 식량 | 썩은 냉동 창고(감염도↑) |
| 강남 테헤란로 | 전자부품·고급 장비 | 고층 층별 탐색, 엘리베이터 함정 |
| 한강 다리 | 이동로 | 병목, 무너지면 배 제작 |
| 잠실 초고층 타워 | 후반 보물 | 꼭대기의 무언가 |
| 남산 송신소(최종) | 구조 신호 | 최종 방어전 |

## 4. 생존 수치
- 배고픔·갈증·피로
- 감염도: 물리면 상승, 100이면 영구 사망·동료 상실. 항생제로 늦출 뿐.
- 정신력: 동료 사망·고립 시 하락, 낮으면 조준 흔들림.
- 한국 계절: 장마(물 쉬움·소리 묻혀 기습 위험), 폭염(갈증 2배), 한파(난방 연료·좀비 느려짐).
- 낮/밤: 밤은 시야 좁고 좀비 많지만 좋은 물건.

## 5. 소리 시스템 (핵심 차별점)
- 행동마다 소음 값: 걷기 1, 뛰기 3, 문 부수기 6, 총 10, 차량 경보 15.
- 원형으로 퍼지고 벽·층에서 감쇠, 화면에 물결로 표시.
- 휴대폰 알람·폭죽으로 좀비 유인.

## 6. 좀비
배회자 / 질주자 / 비명꾼(주변 호출, 우선 처치) / 방호복(근접 강함·화기 약함) / 부풀이(감염 가스 폭발) / 선로 무리(지하철, 빛에 반응) / 보스 「한강의 그것」.

## 7. 거점
아파트 옥상 + 아래층 확보. 빗물 정수기, 옥상 텃밭(계절별), 태양광·발전기, 바리케이드, 작업대, 무전기, 의무실. 며칠마다 습격, 남은 동료와 방어 시설로 자동 방어 후 리포트.

## 8. 제작·장비
분해→재료→조립(우산→철심+천, 소화기→둔기·연막). 삽·쇠파이프·안전모·오토바이 헬멧·석궁·개조 타정총·화염 스프레이. 총은 드물고 탄약 귀함. 무게 제한(무거우면 소음·피로↑).

## 9. 생존자·세력
- 동료(최대 4): 의사, 배달 라이더, 군 전역자, 고등학생 해커, 시장 상인 할머니 — 특기·사연·신뢰도.
- 세력: 한강 뱃사람들(상인), 용산 잔류 부대(가혹한 징발), 종로 약탈단(협상 가능), 방주교회(감염자를 숨긴 비밀).
- 엔딩: 구조 / 서울 재건 / 홀로 탈출 / 전멸.

## 10. 진행 구조
본편 60일 이야기 / 무한 생존 모드(영구 사망) / 메타 성장은 '일지'(도감·설계도)만.

## 11. UI (모바일 세로)
왼손 조이스틱, 오른손 공격·회피·상호작용. 위쪽 생존 수치, 아래 퀵슬롯. 소음 물결·좀비 시야·남은 시간 표시.
