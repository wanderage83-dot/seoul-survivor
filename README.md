# 서울, 잔류자

봉쇄된 서울에서 살아남는 쿼터뷰 좀비 생존 게임. 빌드 도구·의존성 없이 `index.html` 한 파일로 돌아간다.

## 지금 들어 있는 것 (최소판)
- **무대:** 강남역~신논현역 일대(84×100칸, 북쪽이 위). 실제 길 배치를 참고했다.
  - 강남대로(8차로·중앙 버스전용차로)가 세로로 지나고, 위 교차로가 신논현역(봉은사로), 아래 교차로가 강남역(테헤란로·서초대로)이다. 지하철 출구도 있다.
  - 강남대로 동쪽은 좁은 먹자골목, 서쪽은 교부타워(교부문고)·샘성타운 같은 큰 건물. 메가폭스·CGB 영화관, GT타워, 역삼 파이낸스.
  - 상호는 실제 이름을 비튼 패러디다: GS52, CV, 스타벅수, 올리브엉, 다있소, 맥도널두, 온누니약국 등. 가게 종류마다 나오는 물건이 다르다.
  - [M] 또는 🗺 버튼으로 전체 지도를 본다.
- **목표:** 먹자골목 안 청운 오피스텔 옥상 거점에서 7일을 버틴다. 8일째 아침이 되면 승리.
- **하루:** 06:00에 나가 낮에 뒤지고, 17시쯤 해가 지면 좀비가 늘어난다. 거점에서 잠들면 다음 날.
- **건물 안:** 거점이 아닌 건물 문 앞에서 [E/✋]를 누르면 들어간다. 층마다 복도와 방이 있고, 계단으로 오르내린다.
  - 층 수: 가게 2층, 원룸·오피스텔 3~5층, 영화관 3층, 빌딩 4~7층. 1층은 그 가게 물건, 위층은 원룸·사무실 물건이 나온다.
  - 건물 안은 어둡고(손전등만), 층마다 좀비가 있다. 뒤진 상자와 남은 좀비는 그대로 남고, 날이 바뀌면 좀비가 다시 차고 상자 일부가 다시 찬다.
  - 1층 출구로 나오면 그 건물 문 앞으로 돌아온다.
- **생존 수치:** 체력·배고픔·갈증·감염. 물리면 감염이 오르고, 100이 되면 끝. 감염은 잠잘 때마다 +5.
- **소리:** 걷기·달리기·공격·뒤지기 모두 소리를 낸다. 소리를 들은 좀비는 그 자리를 조사하러 온다.
  - 폭죽을 던지면 5초 동안 소리가 나서 좀비를 끌어낼 수 있다.
  - 빨간 불빛이 깜박이는 차의 트렁크를 열면 경보가 10초 동안 울린다.
- **좀비 3종:** 배회자(느림), 질주자(빠름), 비명꾼(보면 소리를 질러 주변을 부름). 눈치채지 못한 좀비를 치면 기습 피해 1.6배.
- **거점:** 들어가면 가방이 창고로 비워진다. 상태(먹기·치료) / 제작(붕대·폭죽·무기·수리) / 시설(빗물 받이·옥상 텃밭·바리케이드) / 챙기기.
- **습격:** 3일마다 밤에 습격이 온다. 바리케이드 단계가 모자라면 식량·물을 잃고 다친다.

## 조작
| | PC | 휴대폰 |
|---|---|---|
| 이동 | WASD·방향키 | 왼쪽 조이스틱 |
| 달리기 | Shift | 🏃 버튼(켜고 끄기) |
| 공격 | Space·클릭 | ⚔ |
| 뒤지기·거점 들어가기 | E | ✋ |
| 폭죽 | F·우클릭 | 🧨 |
| 먹기·마시기·붕대·항생제·폭죽 | 1~5 | 위쪽 빠른 사용 줄 |
| 지도 | M | 🗺 지도 |

## 실행·검사

```
python3 -m http.server 8795
node tests/smoke.cjs http://127.0.0.1:8795
```
